# Repository instructions for Codex and other coding agents

Before changing this repository, read and follow `CLAUDE.md` in full. It is the canonical engineering checklist for the Microschool Ledger marketing site and covers accessibility, SEO, analytics, conversion, performance, security, validation, and deployment-status reporting.

Also read `BRAND.md` before making any visual, typography, color, product-naming, or user-facing copy decision. Do not override either file with inferred conventions from older code.

If these instructions conflict with a direct user request, flag the conflict and follow the direct request. Keep `CLAUDE.md` as the single detailed checklist; update it when a new durable site convention is established rather than duplicating that guidance here.
